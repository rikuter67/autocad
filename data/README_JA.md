# 大阪松竹座 / AutoCAD用データ

元の1階平面に加え、追加された2・3・4・7・8階平面と断面図を反映した概略CADデータです。画像内の文字は図面情報として扱っています。

## 開くファイル

**3Dを編集する場合：`shochikuza_3d_solids.dxf`**

AutoCADデスクトップ版の「開く」でDXFを選択してください。1,643個の独立した `3DSOLID` を含みます。画層は `F01_WALLS`、`F03_SEATING` のように階と部材種別で分かれています。壁・床・階段などを選択して移動、削除、編集できます。独立したソリッドなので、接合部が一体化されているとは限りません。

表示が見つからない場合は `ZOOM` → `E`。斜めから見る場合は `VPOINT` → `1,-1,1` を使用します。画層管理で `F03_*` など対象階だけを表示すると内部を確認しやすくなります。

DXFはAutoCADで開いて「名前を付けて保存」からDWGとして保存できます。このパッケージ自体にはDWGを含みません。

**2Dを編集する場合：`shochikuza_2d_all_floors.dxf`**

6フロアを一覧配置しています。各階を原点に揃えて単独で使う場合は `plan_01F.dxf`、`plan_02F.dxf`、`plan_03F.dxf`、`plan_04F.dxf`、`plan_07F.dxf`、`plan_08F.dxf` を開きます。直線部は閉じたポリライン、部屋名は編集可能な文字です。設備や細かな線は省略した概略の再作図です。

## 原画像との照合

`reference_01F.dxf` などは、原画像の線の輪郭をベクトル化した参照図です。文字や設備記号を含むため、すべての線が壁を意味するわけではありません。編集用の再作図と同じ座標変換を適用しています。

`section_reference.dxf` は追加の断面図をベクトル化したものです。断面から読み取った暫定の床レベルを重ねています。`references` フォルダには元画像も同梱しています。DXFの表示に画像ファイルへのリンクは必要ありません。

## 断面図の反映と未確定事項

以前の1階モデルで仮設定していた壁高さ3.6mを更新し、断面画像から階の高さ関係を推定しました。舞台・客席上部の吹き抜け、2階の奈落開口、3階の舞台、4階のバルコニー、7階の楽屋、8階の稽古場・事務室・屋上を概略で反映しています。

ただし、実寸は未校正です。1階元画像のx=60〜1520を60,000mmとした仮のスケールを引き継いでいます。追加画像は階段コア等の目視アンカーで整列し、断面の建物幅に対応させて高さを算出しました。画像のゆがみ、壁位置の読み違い、階同士の位置ずれは残り得ます。「縮尺1/600」の記載だけではデジタル画像の正しい実寸を確定できません。

| 階 | 暫定床レベル | 平面の有無 |
|---|---:|---|
| 1階 | 0.00m | あり |
| 2階 | 4.83m | あり |
| 3階 | 9.79m | あり |
| 4階 | 14.13m | あり |
| 5階 | 18.22m | 未提供・モデルなし |
| 6階 | 23.80m | 未提供・モデルなし |
| 7階 | 28.07m | あり |
| 8階 | 31.98m | あり |

5・6階は断面に見える高さだけを記録し、平面形状は作成していません。地下階、屋根構造、最上部設備も再現していません。そのため3Dは建物全体の完成モデルではなく、提供階の部分モデルです。`model_3d_cutaway.png` は内部を確認するため手前半分を表示上で切った画像で、DXFの形状は切断していません。

壁厚、建具寸法、細かな開口、階段の上り方向と踊場、客席の傾斜や席数は未確定です。客席は席配置を概略で表す繰り返し部品です。上階の扉や設備は省略している箇所があります。階段周辺の床開口、部材の接合・干渉、構造躯体の成立性は未検証です。

単位はmm。座標変換と高さの設定は `model_parameters.json` に記録しています。実寸の分かる距離を1か所確認して校正すると、平面と断面のスケールを合わせ直せます。

## 形式と検証

3DはR2010 DXFのACISソリッドです。面で囲まれた立体を `3DSOLID` として格納しており、壁・床はAutoCAD Architectureの専用パラメトリック部材ではありません。円形部分は多角形近似です。代替として `shochikuza_3d_mesh_fallback.dxf` にポリフェイスメッシュ版も用意しました。

すべてのDXFを再読み込みし、ファイル構造監査エラー0件を確認しました。3Dソリッド1,643個についてACISデータを再解析し、閉じた形状として復元できることを確認しています。AutoCADアプリ上での実機確認とDWG変換は未実施です。検証結果は `validation.json` にあります。
